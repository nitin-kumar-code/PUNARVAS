# Database Schema

This document outlines the planned entities for the PostgreSQL database.

## Entities

### Habitation
Represents a vulnerable settlement or village.
- **Fields**: ID, Name, Location (Lat/Lon or Geometry), Population, Demographics, Infrastructure Level.

### RiskAssessment
Stores the output of the AI/ML risk engine for a habitation.
- **Fields**: ID, Habitation ID, Hazard Type (Flood, Landslide, etc.), Risk Score (0-100), Probability, Timestamp, AI Confidence.

### CandidateSite
Represents a potential safe zone for relocation.
- **Fields**: ID, Name, Location, Total Area, Current Infrastructure, Base Carrying Capacity.

### SiteAssessment
Stores the evaluation of a candidate site's suitability.
- **Fields**: ID, Candidate Site ID, Adjusted Carrying Capacity, Resource Availability Score, Environmental Impact Score, Timestamp.

### RelocationPlan
A high-level plan generated by the optimization engine.
- **Fields**: ID, Status (Proposed, Approved, Rejected), Created At, Total People Affected, Expected Cost.

### Allocation
Specific assignments mapping vulnerable populations to candidate sites within a plan.
- **Fields**: ID, Relocation Plan ID, Habitation ID, Candidate Site ID, Number of People Allocated, Priority.

### DecisionReceipt
An immutable record of final relocation decisions and their justifications.
- **Fields**: ID, Relocation Plan ID, Approved By, Timestamp, Justification Notes, Digital Signature/Hash.
